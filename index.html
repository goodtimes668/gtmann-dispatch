Help
Getting around
  • Home — today's counts, quick actions, and upcoming bookings.
  • Bookings — every booking; tap one to see details.
  • Calendar — bookings by day. Tap a day to see its jobs or add one for that date.
  • Dispatch — approvals, today's run sheet, equipment returns, 30-day stats, and job sites.
  • Manager — cost summaries, user access, backups, and audit activity (managers only).
  • Use Refresh in the top bar to pull the latest changes.
Requesting a booking
  1. Tap a Quick Action on Home, or + New on Bookings.
  2. Choose the type: Material Delivery, Tool Pickup, Tool Delivery, or Misc Task.
  3. Pick the job site (choose Other to type a name), then describe what's needed with quantities.
  4. Set the date and whether the time is flexible, morning, afternoon, or specific. Mark urgent jobs clearly.
  5. Add an on-site contact, request a helper, or track equipment that needs to come back by a set date.
  6. Attach a photo and add access instructions or other notes if helpful.
  7. Tap Submit Booking Request. It starts as Pending until approved.

The estimated dispatch cost updates as you fill in the form. You can edit your own booking while it is still pending.

Dispatcher assignments and returns
  • Dispatchers can assign a driver and vehicle from the booking details.
  • The app flags possible same-day driver or truck conflicts. Confirm the jobs can be covered before saving an override.
  • Outstanding equipment appears on the Dispatch Board. Open its booking and mark it returned when it is back at the yard.
  • Managers can give a backup dispatcher access from Manager → User Access.
Booking statuses
  • Pending — waiting for approval.
  • Approved — scheduled and ready to go.
  • In Progress — the job has started.
  • Done — the job is complete.
  • Declined — not going ahead.

Open any booking and tap Add to Outlook to save it to your calendar.

Dispatchers: approving & running jobs
  • Open a pending booking to Approve or Decline it.
  • Approved jobs can be started with Start Job, then finished with Mark Complete.
  • Dispatchers can edit or delete any booking.
  • Manage job sites from the Dispatch tab. Start typing an address and pick a suggestion; the round trip from Faithwood Farms is calculated for you.
Managers
  • Pick a date range to see estimated dispatch spend in total and by site.
  • Under User Access, set each person's role to Member, Dispatcher, or Manager.
  • Backups run daily. Use Create Backup Now before major changes and download it for safekeeping.
Working offline

If you lose signal, new bookings are saved on this device and sync automatically when the connection returns. A banner on Home shows anything waiting to sync. If an item can't sync, discard it and submit it again.

Roles & access
  • Member — create bookings, edit your own pending bookings, see the team schedule.
  • Dispatcher — approve, decline, start, complete, edit, and delete bookings; manage job sites.
  • Manager — everything a dispatcher can do, plus cost summaries and user roles.

New accounts start as Member. Ask a manager if you need more access.
